# Horizon — Full-Stack Finance Dashboard 💳

A full-stack banking dashboard prototype built to explore account aggregation, transaction views, transfers, financial analytics, and modern application architecture.

> **Status:** Portfolio project using Plaid Sandbox / test integrations. This is not a production banking system.

## ✨ Highlights

- User authentication and account workflows
- Banking account connection flow using Plaid Sandbox
- Transaction and balance views
- Transfer workflow UI
- Financial analytics and charts
- Type-safe forms and reusable UI components
- Responsive dashboard experience

## 🛠️ Tech stack

- **Framework:** Next.js 16, App Router
- **Language:** TypeScript
- **Backend:** Appwrite / Node Appwrite
- **Banking integration:** Plaid Sandbox
- **UI:** Tailwind CSS, shadcn-style components, Radix UI, Lucide
- **Charts:** Recharts

## 🚀 Run locally

```bash
git clone https://github.com/AyeshaK007/jsm_banking.git
cd jsm_banking
npm install
npm run dev
```

Open `http://localhost:3000`.

Environment variables are required for the connected services; keep all credentials out of the repository.
